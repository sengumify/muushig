МУУШИГ — mobile web scoreboard

Энэ хувилбарын гол зүйлс:
- Тоглогчдын оноо оруулах хэсэг байнга ижил дарааллаар байна. Ажил эргэхэд зөвхөн “Ажил” тэмдэг тухайн тоглогч руу шилжинэ.
- Ажил ээлж бүрийн дараа дараагийн суудал руу эргэнэ.
- Онооны хүснэгт босоо дэлгэц дээр доор, хэвтээ дэлгэц дээр баруун талд байна; дэлгэцийн хэмжээнд динамикаар тэлнэ.
- Хүснэгтээр харах / Хураах горимтой.
- Тоглогч бүрт зураг авах боломжтой. Зураг браузерт хадгалахаас өмнө 220x220 болгож багасгана.
- Амжилттай Ээлж оруулах бүрт cash-register маягийн богино SFX тоглоно.
- “Нийт тоглолтыг шууд дуусгах” жижиг сонголт оноо оруулах хэсгийн доор байна.
- Дуусаагүй Гараа төлбөрийн тооцоонд орохгүй. Зөвхөн дууссан Гараануудын өр тооцогдоно.
- Оноо дутуу үед “Оноо оруулах дутуу” гэж мэдэгдэнэ.
- Төлөв localStorage-д автоматаар хадгалагдана. Ижил браузераар хуудсыг дахин нээвэл үргэлжилнэ.

Файл:
- index.html — сервергүй, нэг файлтай web app.
